

\# SmartPay Frontend Architecture



\## Components

Reusable interface elements.



\- common: Buttons, inputs, badges, loaders.

\- dashboard: Dashboard cards and charts.

\- payments: Payment-related components.

\- layout: Sidebar, navbar and page navigation.



\## Pages



\- auth: Login and registration.

\- dashboard: Main dashboard.

\- payments: Payment creation and details.

\- fraud: Fraud risk information.

\- webhooks: Webhook endpoints and delivery monitoring.



\## Other folders



\- layouts: Shared application layouts.

\- services: Backend API integration using Axios.

\- hooks: Reusable React hooks.

\- context: Authentication and application state.

\- utils: Formatting and helper functions.

\- routes: React Router configuration.

\- config: Environment and app configuration.

\- test: Frontend tests.

\- assets: Images, icons and static assets.
